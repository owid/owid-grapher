---
title: Unordered List
---

An unordered (bulleted) list. Produced automatically from Google Docs
bullet formatting — authors don't usually write this block explicitly
in ArchieML. Nested lists are not supported.

## Properties

- `items`: The bullet points. Not written as a key — each bulleted line
  in the Google Doc becomes one item, keeping its rich text (bold,
  italic, links). Nested bullets are not supported.
