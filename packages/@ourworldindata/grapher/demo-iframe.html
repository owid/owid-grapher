Grapher iframe demo

Each chart is mounted inside an iframe whose document is written into its srcdoc attribute, the way some host sites isolate the chart from their own styles and scripts. Grapher then thinks it is in an iframe, as it is on OWID embeds, which changes how links and buttons behave.

Default options

The config has a slug and isPublished, so the title and "Explore the data" link to /grapher/<slug>, which doesn't exist on the host site. The donate button only shows in iframes.

canonicalUrl: null, hideDownloadButton: true, hideDonateButton: true

No links to a chart page, and no share, download or donate button.
